# ManiSkill PickCube → NaiviBridger Training Pipeline
*Complete pipeline from ManiSkill robot demonstrations to NaiviBridger visual navigation model*

⚠️ **Important**: This pipeline is designed to be used **inside the NaiviBridger repository**.  
You must clone NaiviBridger first and place `maniskill_pickcube/` under the repository root.

2. Convert demos to **NaiviBridger format** (images + pickle)
3. Verify dataset integrity
4. Train a **diffusion model** for visual navigation using **NaiviBridger**

## Install `diffusion_policy` Submodule (Required)

NaiviBridger training depends on the `diffusion_policy` package.  
If you see `ModuleNotFoundError: No module named diffusion_policy`, install it from the repo subdirectory.


Activate your training environment first:

```bash
conda activate navibridge
```

Then install the package in editable mode:

```bash

pip install -e .
```

### 3) Quick sanity check

```bash
python -c "import diffusion_policy; print('diffusion_policy import OK')"
```

If this prints successfully, the dependency is installed correctly.

## ManiSkill Data Source

### What is ManiSkill?

[ManiSkill](https://maniskill.readthedocs.io/) is a unified benchmark for learning generalizable robotic manipulation skills. It provides high-quality demonstration data for various manipulation tasks.

### Available Demonstration Types

ManiSkill provides three types of demonstrations:

1. **Motion Planning** (Recommended for NaiviBridger)
   - Generated using sampling-based motion planners
   - Deterministic, smooth trajectories
   - Always includes RGB observations
   - Best quality for imitation learning

2. **RL Policy**
   - Generated by trained reinforcement learning agents
   - May have suboptimal actions
   - Quality varies by task

3. **Teleoperation**
   - Human-controlled demonstrations
   - High quality but limited quantity
   - Requires special hardware to generate

### Installation and Demo Generation

#### Option 1: Install ManiSkill and Generate Demos

```bash
# Install ManiSkill
pip install mani-skill

# Generate motion planning demos with RGB for PickCube task
python -m mani_skill.trajectory.replay_trajectory \
  --traj-path ~/.maniskill/demos/PickCube-v1/motionplanning/trajectory.h5 \
  --save-traj \
  --obs-mode rgbd \
  --num-procs 10

# This creates: ~/.maniskill/demos/PickCube-v1/motionplanning/trajectory.rgb.pd_ee_delta_pos.physx_cpu.h5
```

#### Option 2: Download Pre-generated Demos

ManiSkill stores demos in `~/.maniskill/demos/` by default. If demos don't exist, ManiSkill will automatically download them on first use.

```bash
# List available demos
ls ~/.maniskill/demos/PickCube-v1/motionplanning/

# Expected files:
# - trajectory.h5 (base trajectory without RGB)
# - trajectory.rgb.pd_ee_delta_pos.physx_cpu.h5 (with RGB observations)
```

### Recommended Data Source for This Pipeline

For **PickCube-v1** task with NaiviBridger training:

```bash
# Path to motion planning demos with RGB
~/.maniskill/demos/PickCube-v1/motionplanning/trajectory.rgb.pd_ee_delta_pos.physx_cpu.h5
```

**Why this file?**
- Contains 1000 expert trajectories
- Each trajectory has RGB images (128×128×3)
- Actions are continuous 4D vectors: [x, y, z, gripper]
- All trajectories successfully complete the task

### Demo File Structure

The HDF5 file contains:

```
trajectory.rgb.pd_ee_delta_pos.physx_cpu.h5
├── traj_0/
│   ├── actions          # (T, 4) - [x, y, z, gripper] delta actions
│   ├── obs/
│   │   └── sensor_data/
│   │       └── base_camera/
│   │           └── rgb  # (T+1, 128, 128, 3) - RGB images
│   └── env_states       # (T+1, ...) - environment states
├── traj_1/
└── ...
```

### Other ManiSkill Tasks

This pipeline can be adapted for other ManiSkill tasks:

### Output Format

The conversion creates:
- `pickcube_traj*/` - Folders for each trajectory
- `*.jpg` - Extracted RGB observations (96×96)
- `traj_data.pkl` - Position and yaw data
- `traj_names.txt` - List of trajectory names

Output structure:
```
dataset/pickcube_maniskill/
├── pickcube_traj0/
│   ├── 0.jpg
│   ├── 1.jpg
│   ├── ...
│   └── traj_data.pkl
├── pickcube_traj1/
├── ...
└── traj_names.txt
```

## Training

### Configuration File

Training configuration in `pickcube_maniskill.yaml`:

```yaml
# Model configuration
model_type: navibridge
vision_encoder: navibridge_encoder
encoding_size: 256
image_size: [96, 96]           # Important: must be list format

# Training configuration
batch_size: 128
num_epochs: 50
lr: 1e-4
optimizer: adamw

# Action prediction
len_traj_pred: 8               # Must be 8 (U-Net architecture requirement)
action_dim: 2                  # 2D position deltas (dx, dy)
learn_angle: false

# Diffusion model
num_diffusion_iters: 10
sampler: euler
prior_policy: gaussian
```

### Run Training

```bash
# Activate environment
conda activate navibridge

# Go to training directory
cd NaiviBridger/train

# Start training
python train.py -c ../maniskill_pickcube/pickcube_maniskill.yaml
```

### Monitor Training

```bash
# View latest runs
ls -lht logs/navibridge/ | head -5

# View training logs
tail -f logs/navibridge/<run_name>/wandb/latest-run/logs/debug.log

# Check GPU usage
watch -n 1 nvidia-smi
```

### Expected Training Metrics

Based on verification results:

- **diffusion_loss**: ~0.45-0.55
- **dist_loss**: ~130-140
- **total_loss**: ~0.44-0.56
- **Training speed**: ~2.4 it/s (per batch)
- **Checkpoint size**: ~73MB (model) + 73MB (EMA)

## FAQ

### Q: "Image not found in cache" warnings during training?

A: These warnings are normal and don't affect training. They indicate images not yet in LMDB cache on first access.

### Q: Out of memory (OOM) errors?

A: Adjust in `pickcube_maniskill.yaml`:
```yaml
batch_size: 64              # Reduce from 128
num_workers: 4              # Reduce from 8
```

### Q: Training is too slow?

A: Check:
- Is GPU being used by other processes: `nvidia-smi`
- Is data on SSD (not network storage)
- Is `num_workers` reasonable (recommended 4-8)

### Q: How to resume training?

A: Add to `pickcube_maniskill.yaml`:
```yaml
load_run: navibridge/navibridge_pickcube_<timestamp>
```
Then run training normally.

### Q: Can I use other ManiSkill tasks?

A: Yes. You'll need to modify:
1. `process_maniskill_pickcube.py` - Adjust action extraction logic
2. `pickcube_maniskill.yaml` - Update `action_dim` and task name
3. `train/vint_train/data/data_config.yaml` - Add new task configuration

## Technical Details

### Data Conversion Pipeline

1. **Read h5 file**: Use h5py to read ManiSkill demonstrations
2. **Extract images**: RGB observations, resize 128×128 → 96×96
3. **Extract actions**: TCP position deltas (dx, dy)
4. **Save data**:
   - Images saved as JPG (96×96)
   - Actions saved as pickle (position + yaw)
5. **Build index**: Create `traj_names.txt`

### Training Architecture

- **Vision Encoder**: EfficientNet-B0 + Multi-Head Attention
- **Noise Predictor**: Conditional U-Net 1D
- **Distance Predictor**: MLP with attention layers
- **Diffusion Scheduler**: Karras VE (Variance Exploding)
- **Prior Policy**: Gaussian (optional CVAE)
